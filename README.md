## 🏛️ About VIRSA
Nestled in the heart of Amravati on Badnera Road, **VIRSA** is a testament to the passion for exquisite dining nurtured by **The New Eagle Restaurant**. Our menu is a canvas that honors traditional Indian heritage while exploring modern culinary horizons with Continental, Oriental, Sizzlers, Clay Pot Biryanis, and artisan cafe brews.

## 🚀 Getting Started

Clone the repository and open `index.html` in any modern web browser:

```bash
git clone git@github.com:amityadav-72/VIRSA.git
cd VIRSA
```

Or run locally with Python:

```bash
python -m http.server 5500
```

Then visit [http://localhost:5500](http://localhost:5500) in your browser.
